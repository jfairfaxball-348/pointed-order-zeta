# Terminology

## Frozen mathematical terms

**multiplicative order** — \(\operatorname{ord}_p(a)\), the order of \(a\bmod p\) in \(\mathbf F_p^\times\).

**residual index** — \(I_a(p)=(p-1)/\operatorname{ord}_p(a)\), equivalently the index of \(\langle a\bmod p\rangle\) in \(\mathbf F_p^\times\).

**Kummer field / radical extension in this project** — provisionally \(K_n(a)=\mathbf Q(\zeta_n,a^{1/n})\), with exact field-theoretic caveats to be made explicit during derivation.

## Provisional project terms

**Pointed Order Zeta** — project name, not a novelty claim.

**Artin–Kummer order spectrum** / **order spectrum** — provisional name for the transform \(\Delta_a(z)\). Do not present as established terminology until the literature audit.

**Pointed algebraic group** — informal project shorthand for a group object together with a chosen rational point; use standard literature terminology once identified.

## Terms to use cautiously

**spectrum** — currently metaphorical/transform language. It does not yet denote the spectrum of an operator, scheme, or C*-algebra.

**zeta function** — used because of the Euler product packaging; no meromorphic continuation or functional equation is implied.

**fractional pole** — avoid unless a precise local analytic model is proved. “Branch-type singularity” is also a research question, not established terminology.

**motivic** / **Hodge-theoretic** — do not use as significance language until a genuine realization-theoretic construction requires it.
