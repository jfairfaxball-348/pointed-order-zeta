# Tests

Session 2 exact tests cover multiplicative order, residual index, the finite-group divisibility criterion, composite (n), the necessary condition (n\mid p-1), negative bases, perfect-power bases, and primes dividing (a).

Session 4 adds analytic-pilot consistency tests for the source-matched positive non-perfect-power Kummer degree specialization, the (g_z) prime-power formula and (z=0) endpoint, the (k=1)/(k\ge2) logarithmic decomposition, the full-zeta finite omitted-prime factor, and the cleaner omitted-prime normalization by \(\zeta_a(s)\).

The tests verify implementation identities only; they are not evidence for density or analytic-continuation theorems.
